# Агент для анализа курса валют
## Тулы

- Ищет актуальный курс доллара к нужной валюте.
- Сохраняет курс в базу данных PostgreSQL.
- Использует сохранённую историю курсов для прогнозирования цены на ближайшие 7 дней.
- Работает через командную строку.

Пример запроса:

```text
Найди курс доллара к рублю, сохрани результат в PostgreSQL и предскажи цену на 7 дней вперёд.
```

## Установка

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` и заполните его по оьбразцу `.env.example`:

```env
GROQ_API_KEY=your_groq_api_key_here
DB_PASSWORD=your_postgres_password
```

3. Создайте и укажите базу данных в параметрах.

## Запуск

```bash
python3 agent_search.py
```

## Что сохраняется в базе данных

Агент записывает данные в таблицу `usd_rates` со следующими полями:

- `rate_date` — дата курса;
- `rate` — значение курса;
- `currency_pair` — валютная пара, например `USD/RUB`;
- `updated_at` — время обновления.

## Предсказание на 7 дней

На основе исторических данных из PostgreSQL агент строит прогноз курса на следующие 7 дней с помощью модели amazon/chronos-2.
